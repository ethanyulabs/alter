A browser for you and your AI agent.

alter is a macOS browser with Arc-style Spaces and a vertical sidebar. Agents drive it through the alter CLI and a scripting runtime, inside the Spaces you are already signed in to — and you can take over whenever you want, then hand it back.

Install

Run this in Terminal. It downloads the latest release, verifies its SHA256, installs alter.app into /Applications (~/Applications if that is not writable) and links the CLI to ~/.local/bin/alter.

curl -fsSL https://github.com/ethanyulabs/alter/releases/latest/download/install.sh | bash

alter currently supports Apple Silicon Macs (M1 or later) on macOS 13 or newer. Upgrade later with alter upgrade.

Prefer a disk image? Download the DMG from the latest release. The app is not notarized, so macOS may block it the first time you open it: go to System Settings → Privacy & Security → Open Anyway. Installing with the command above does not hit this.

What you get

Spaces

Each Space has its own cookies and storage. Keep work and personal sessions apart and switch from the sidebar.

Sidebar tabs

Vertical tabs, pinned tabs, drag to reorder, and inactive tabs archived automatically.

Command bar

Press ⌘T to open a URL, search, or jump to a tab, Space, bookmark or history entry.

Split view & Peek

Two tabs side by side, and Shift-click a link to preview it without leaving the page.

Import from Chrome or Arc

Bring bookmarks, recent history and cookies into a Space, so you stay signed in.

Updates

alter tells you when a new version is out; alter upgrade installs it.

For AI agents

Agents run scripts with alter nodejs using the TaskSpace / Page API: open pages, read snapshots, click, fill forms, take screenshots and download files. The agent's cursor and actions are shown on the page; when it hits a sign-in or a captcha it hands control to you, and waits until you hand it back.

alter nodejs <<'EOF'
const ts = await taskSpace("demo");
const page = ts.page("p1");
await page.goto("https://example.com");
console.log(await page.title());
await ts.finish();
EOF

Teach your agent how to use alter by installing the bundled skill into Claude Code or Codex:

alter skill install

It copies alter-browser into ~/.claude/skills and ~/.codex/skills (whichever exist); use --target <dir> for other agents. Playwright can also connect through connectOverCDP.

FAQ

Does it run on Intel Macs?

Not yet. Releases are built for Apple Silicon only.

macOS says the app can't be opened.

That happens when the DMG was downloaded in a browser. Open System Settings → Privacy & Security and click Open Anyway, or reinstall with the command above.

How do I uninstall?

Delete alter.app from /Applications (or ~/Applications) and ~/.local/bin/alter; run alter skill uninstall first if you installed the skill. Your data lives in ~/Library/Application Support/alter.
