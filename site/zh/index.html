你和 AI agent 共用的浏览器。

alter 是一个 macOS 浏览器，有 Arc 风格的 Space 和竖排的侧边栏。agent 通过 alter 命令行和脚本运行时操作它，就在你已经登录的 Space 里干活；你随时可以接管，做完再交还给它。

安装

在终端运行下面这条命令。它会下载最新版本、校验 SHA256，把 alter.app 装进 /Applications（不可写时装进 ~/Applications），并把命令行链接到 ~/.local/bin/alter。

curl -fsSL https://github.com/ethanyulabs/alter/releases/latest/download/install.sh | bash

目前只支持 Apple Silicon 的 Mac（M1 及更新），系统需要 macOS 13 或更新。之后用 alter upgrade 升级。

想用磁盘镜像？可以从最新版本下载 DMG。app 没有经过公证，第一次打开时 macOS 可能会拦下它：到 系统设置 → 隐私与安全性 → 仍要打开。用上面的命令安装不会遇到这个问题。

功能

Space

每个 Space 有自己的 Cookie 和存储，工作和个人的登录状态互不影响，在侧边栏底部切换。

侧边栏标签

竖排标签、固定标签、拖拽排序，不活跃的标签自动归档。

命令栏

按 ⌘T，一个输入框完成打开网址、搜索、跳到标签、Space、书签或历史。

分屏与 Peek

两个标签并排看；按住 Shift 点链接，不离开当前页就能预览。

从 Chrome / Arc 导入

把书签、最近的历史和 Cookie 导入某个 Space，网站不用重新登录。

更新

有新版本时 alter 会提示你，alter upgrade 一条命令装好。

给 AI agent

agent 用 alter nodejs 运行脚本，通过 TaskSpace / Page API 打开页面、读快照、点击、填表、截图、下载文件。页面上会显示 agent 的光标和动作；遇到登录或验证码时，它把控制权交给你，等你交还后再继续。

alter nodejs <<'EOF'
const ts = await taskSpace("demo");
const page = ts.page("p1");
await page.goto("https://example.com");
console.log(await page.title());
await ts.finish();
EOF

把随 app 附带的 skill 装进 Claude Code 或 Codex，agent 就知道怎么用 alter：

alter skill install

它会把 alter-browser 复制到 ~/.claude/skills 和 ~/.codex/skills（只装到已存在的目录）；其他 agent 用 --target <dir> 指定目录。Playwright 也可以通过 connectOverCDP 直接连上来。

常见问题

支持 Intel 的 Mac 吗？

暂时不支持，发布的版本只针对 Apple Silicon。

macOS 提示无法打开 app。

在浏览器里下载 DMG 时会这样。打开 系统设置 → 隐私与安全性，点「仍要打开」；或者用上面的命令重新安装。

怎么卸载？

删除 /Applications（或 ~/Applications）里的 alter.app 和 ~/.local/bin/alter；装过 skill 的话先运行 alter skill uninstall。数据在 ~/Library/Application Support/alter。
